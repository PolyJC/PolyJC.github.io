# Jaechul Ju — Personal Research Website

Personal academic website for Jaechul Ju, Ph.D., a polymer scientist and postdoctoral fellow at The University of Texas at Austin.

This is a static HTML, CSS, and JavaScript website. No build step or paid service is needed.

## Publishing with GitHub Pages

Use the repository PolyJC/PolyJC.github.io. Select Settings > Pages > Deploy from a branch, then main and /(root).

Intended public URL: https://polyjc.github.io/

## Editing

- index.html: biography, research, publications, background, and contact.
- styles.css: responsive design.
- app.js: navigation and publication filters.
- jaechul-ju.jpg and monogram.svg: portrait and favicon.

Biography follows the owner's CV. The publication list was reconciled with the owner's CV, public Google Scholar profile, and publisher/DOI records on October 19, 2026. It contains all 14 peer-reviewed journal articles, with the original eight also available through the Selected work filter. Conference abstracts, the dissertation, and patents are outside this journal-article list.
